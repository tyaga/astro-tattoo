# Плеяды — генератор эскиза татуировки

Интерактивный инструмент, который строит эскиз татуировки звёздного скопления
Плеяды (M45) по реальным астрономическим данным и готовит его к переносу на кожу.

**Демо:** https://tyaga.github.io/pleiades-tattoo/

## Что умеет

- **Настоящие координаты.** Каталог Gaia DR3 (выгрузка VizieR I/355) — 3195 звёзд
  в радиусе 2° вокруг центра скопления, гномоническая проекция на плоскость.
- **Размер точки из звёздной величины.** Диаметр пропорционален потоку в степени
  «контраста», ограничен минимумом и максимумом.
- **Квантование размеров.** Диаметры округляются до заданного шага — мастеру
  нужен ограниченный набор «калибров», а не 40 неразличимых размеров.
- **Реальный масштаб.** Полотно задаётся в сантиметрах, SVG экспортируется
  с физическими размерами в миллиметрах и печатается 1:1.
- **Спецификация для мастера.** Текстовый файл с таблицей всех точек:
  имя, звёздная величина, координаты X/Y в мм от угла, диаметр.
- **Примерка.** Под эскиз можно подложить фотографию своего запястья
  (масштабируется по линейке в кадре) и снимок Плеяд для сравнения —
  обе подложки в экспорт не попадают.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

## Обновление каталога

Свежая выгрузка из VizieR (параметры запроса записаны в шапке `stars.csv`):

```bash
curl -o stars.csv 'https://vizier.cds.unistra.fr/viz-bin/asu-txt?-source=I/355/gaiadr3&-c=M45&-c.rm=120&-c.geom=r&-out=RA_ICRS,DE_ICRS,Gmag,Source&-out.max=5000&Gmag=%3C14'
node convert_stars.js   # stars.csv → src/data/stars.json
```

## Данные и лицензии

- Каталог звёзд: [Gaia DR3](https://cdsarc.cds.unistra.fr/viz-bin/cat/I/355),
  Gaia Collaboration (2022), через VizieR / CDS.
- Фотография скопления: NASA/ESA/AURA/Caltech, общественное достояние
  ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pleiades_large.jpg)).

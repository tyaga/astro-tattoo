# Астро·тату — генератор эскизов созвездий

Интерактивный инструмент, который строит эскиз татуировки созвездия, астеризма
или звёздного скопления по реальным астрономическим данным и готовит его
к переносу на кожу.

**Демо:** https://tyaga.github.io/astro-tattoo/

## Объекты

Плеяды (M45), Ясли (M44), Гиады, Пояс Ориона, Орион целиком, Большая Медведица,
Малая Медведица с Полярной, Кассиопея, Южный Крест, Лира, Лебедь,
Северная Корона, Дельфин.

Список задаётся в [`src/data/targets.json`](src/data/targets.json): центр поля,
радиус выборки, каталог-источник и собственные имена ярких звёзд. Добавить
новый объект — значит дописать туда одну запись.

## Что умеет

- **Настоящие координаты.** Gaia DR3 для богатых скоплений, Hipparcos для ярких
  созвездий (в Gaia самые яркие звёзды засвечены). Гномоническая проекция
  на плоскость вокруг центра объекта.
- **Размер точки из звёздной величины.** Диаметр пропорционален потоку в степени
  «контраста», ограничен минимумом и максимумом.
- **Квантование размеров.** Диаметры округляются до заданного шага — мастеру
  нужен ограниченный набор «калибров», а не 40 неразличимых размеров.
- **Реальный масштаб.** Полотно задаётся в сантиметрах, SVG экспортируется
  с физическими размерами в миллиметрах и печатается 1:1.
- **Нормированный размер рисунка.** Задаётся не поле зрения, а поперечник
  татуировки в сантиметрах. При смене объекта он сохраняется: Лира ляжет ровно
  туда же, где были Плеяды, хотя на небе она в пять раз крупнее.
- **Снимок неба под эскизом.** Для каждого объекта подложка рендерится сервисом
  CDS hips2fits в той же гномонической проекции и с тем же центром, что и эскиз,
  поэтому точки ложатся на звёзды снимка без ручной подгонки.
- **Спецификация для мастера.** Текстовый файл с таблицей всех точек:
  имя, звёздная величина, координаты X/Y в мм от угла, диаметр.
- **Примерка на коже.** Телесный фон и реалистичные цвета чернил (свежая,
  зажившая, серый вош, индиго, сепия, белая), фотография своего запястья
  как подложка с калибровкой по линейке в кадре, снимок скопления для сверки.
  Подложки в экспорт не попадают, а сам экспорт по умолчанию приводится
  к чёрному по белому.
- **Пресеты.** Удачные компоновки сохраняются в браузере вместе с объектом.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

## Данные

Каталоги звёзд и снимки неба **не хранятся в репозитории** — их выгружает из CDS
скрипт [`scripts/fetch-catalogs.mjs`](scripts/fetch-catalogs.mjs)
в `src/data/catalogs/` и `src/data/photos/`. Скрипт запускается автоматически
перед `dev` и `build` (в том числе в GitHub Actions) и пропускает уже скачанное:

```bash
npm run fetch         # докачать недостающие каталоги
npm run fetch:force   # перекачать всё заново
```

Он же проставляет звёздам собственные имена: ищет ближайшую звезду подходящей
яркости к координатам из `targets.json` и предупреждает в логе, если кого-то
не нашёл.

## Источники и лицензии

- [Gaia DR3](https://cdsarc.cds.unistra.fr/viz-bin/cat/I/355) — Gaia
  Collaboration (2022), через VizieR / CDS.
- [Hipparcos](https://cdsarc.cds.unistra.fr/viz-bin/cat/I/239) — ESA (1997),
  через VizieR / CDS.
- Снимки неба: [hips2fits](https://alasky.cds.unistra.fr/hips-image-services/hips2fits)
  (CDS) по обзорам DSS2 color (STScI/ESO) для тесных полей и
  Mellinger «Milky Way Panorama» для широких.

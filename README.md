# Астро·тату — генератор эскизов созвездий

Интерактивный инструмент, который строит эскиз татуировки созвездия, астеризма
или звёздного скопления по реальным астрономическим данным и готовит его
к переносу на кожу.

**Демо:** https://tyaga.github.io/astro-tattoo/

Интерфейс на русском, английском, исландском и нидерландском — язык
определяется по браузеру и переключается в шапке.

## Объекты

31 объект, сгруппированный в окне выбора:

**Знаки зодиака:** Овен, Телец, Близнецы, Рак, Лев, Дева, Весы, Скорпион,
Стрелец, Козерог, Водолей, Рыбы.

**Созвездия и астеризмы:** Орион, Большая Медведица, Кассиопея, Южный Крест,
Лира, Лебедь, Северная Корона, Дельфин, Малая Медведица, Волопас, Возничий,
Орёл, Стрела, Жираф, Геркулес, Южная Корона, Заяц, Журавль.

**Скопления:** Плеяды (M45).

Список задаётся в [`src/data/targets.json`](src/data/targets.json): центр поля,
каталог-источник и собственные имена ярких звёзд. Настройки по умолчанию туда
писать не нужно — они считаются по данным объекта, см. ниже. Добавить новый
объект — значит дописать одну запись.

## Интерфейс

Слева эскиз во всю свободную высоту, под ним итог: поперечник рисунка, число
точек и набор калибров. Справа одна панель с четырьмя вкладками по шагам
работы:

| Вкладка | О чём |
| --- | --- |
| **Рисунок** | объект, сколько звёзд, линии фигуры |
| **Вид** | размер, разворот, зеркала, точки, подписи |
| **Тело** | тон кожи, чернила, фото своего запястья, снимок неба |
| **Печать** | экспорт, калибры, полотно, сетка, пресеты |

Объект выбирается в полноэкранном окне с поиском и миниатюрами, на которых
видна фигура созвездия.

На телефоне панель превращается в нижнюю шторку — повторный тап по своей
вкладке складывает её, и эскиз занимает весь экран. Рисунок двигается пальцем,
щипок двумя пальцами меняет размер и разворот. На десктопе то же делается
перетаскиванием, Shift + перетаскиванием и ⌘/Ctrl + колесом для приближения
предпросмотра.

## Что умеет

- **Настоящие координаты.** Gaia DR3 для богатых скоплений, Hipparcos для ярких
  созвездий (в Gaia самые яркие звёзды засвечены). Гномоническая проекция
  на плоскость вокруг центра объекта.
- **Поле по границам созвездия.** Радиус выборки считается по настоящим границам
  IAU, а не по размеру фигуры: при отдалении звёзды не обрываются по кругу.
  У Жирафа это 40° — в поле попадает и Глизе 445, звезда, к которой через
  40 000 лет ближе всего подойдёт «Вояджер-1» (она отмечена значком зонда).
- **Линии фигуры.** По данным d3-celestial, привязанным к нашему каталогу.
  Показ линий и судьба поля — независимые переключатели: линии задают, какие
  звёзды образуют фигуру, даже когда сами не рисуются. Поэтому «только фигуру»
  можно оставить и без линий: на коже будут одни звёзды созвездия, без поля
  и без соединений.
- **Размер точки из звёздной величины.** Диаметр пропорционален потоку в степени
  «контраста», ограничен минимумом и максимумом. Опорная яркость берётся
  по ярчайшей звезде самой фигуры, иначе случайное светило в широком поле
  (Вега рядом с Геркулесом, Ригель у Зайца) сплющивает всю градацию.
- **Квантование размеров.** Диаметры округляются до заданного шага — мастеру
  нужен ограниченный набор «калибров», а не 40 неразличимых размеров.
- **Реальный масштаб.** Полотно задаётся в сантиметрах, SVG экспортируется
  с физическими размерами в миллиметрах и печатается 1:1.
- **Нормированный размер рисунка.** Задаётся не поле зрения, а поперечник
  татуировки в сантиметрах.
- **Вид по умолчанию считается сам.** Пресеты не прописаны руками, а выводятся
  из данных объекта ([`src/lib/autopreset.ts`](src/lib/autopreset.ts)):
  предел яркости — по самой тусклой звезде фигуры с запасом; поперечник
  татуировки растёт с числом её звёзд (2.8 см + 0.22 см на звезду), а затем
  проверяется на слипание — если просвет между краями соседних точек меньше
  1.1 мм, рисунок увеличивается; максимальный диаметр точки берётся от размера
  рисунка, минимальный ограничен возможностями иглы (0.35 мм), а контраст
  подбирается так, чтобы самая тусклая звезда фигуры пришлась ровно
  на минимальный диаметр — весь диапазон яркостей оказывается использован;
  шаг квантования даёт мастеру около четырёх калибров. Поле вокруг фигуры
  показывается целиком, приглушается или убирается — смотря сколько лишних
  звёзд попало в кадр. В `targets.json` остаются только поправки, которых
  из каталога не выведешь: привычный разворот Скорпиона и сдвиг поля Жирафа.
- **Своя настройка у каждого объекта.** Ваши правки запоминаются отдельно
  по объектам; «вид по умолчанию» и «Сбросить всё» возвращают к расчётному.
- **Спецификация для мастера.** Текстовый файл с таблицей всех точек:
  имя, звёздная величина, координаты X/Y в мм от угла, диаметр.
- **Примерка на коже.** Телесный фон и реалистичные цвета чернил, фотография
  своего запястья как подложка с калибровкой по линейке в кадре, снимок неба
  для сверки. Подложки в экспорт не попадают, а сам экспорт по умолчанию
  приводится к чёрному по белому. Отдельная кнопка «Примерка PNG» делает
  обратное: сохраняет точки поверх вашего фото — без линий фигуры, подписей
  и сетки, то есть ровно то, что окажется на коже.
- **Снимок неба под эскизом.** Для каждого объекта подложка рендерится сервисом
  CDS hips2fits в той же гномонической проекции и с тем же центром, что и эскиз,
  поэтому точки ложатся на звёзды снимка без ручной подгонки.
- **Пресеты.** Удачные компоновки сохраняются в браузере вместе с объектом.
- **Ссылка на эскиз.** Кнопка «Ссылка» кладёт все параметры рисунка в адрес
  страницы; личная примерка (фото запястья, тема, масштаб предпросмотра)
  остаётся в своём браузере и по ссылке не передаётся.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

## Данные

Каталоги звёзд, линии фигур и снимки неба **не хранятся в репозитории** — их
выгружает скрипт [`scripts/fetch-catalogs.mjs`](scripts/fetch-catalogs.mjs)
в `src/data/catalogs/`, `src/data/lines/` и `src/data/photos/`. Скрипт
запускается автоматически перед `dev` и `build` (в том числе в GitHub Actions)
и пропускает уже скачанное:

```bash
npm run fetch         # докачать недостающее
npm run fetch:force   # перекачать всё заново
```

Он же проставляет звёздам собственные имена, считает радиус выборки по границам
созвездия и привязывает вершины линий к ближайшим звёздам, предупреждая в логе
обо всём, что не нашлось.

  через VizieR / CDS.
- Линии фигур и границы созвездий:
  [d3-celestial](https://github.com/ofrohn/d3-celestial) © Olaf Frohn,
  лицензия BSD-3.
- Снимки неба: [hips2fits](https://alasky.cds.unistra.fr/hips-image-services/hips2fits)
  (CDS) по обзорам DSS2 color (STScI/ESO) для тесных полей и
  Mellinger «Milky Way Panorama» для широких.
